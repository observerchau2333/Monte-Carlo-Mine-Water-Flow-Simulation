# 蒙特卡洛矿井水流扩张模拟

English version: [README.md](README.md)

本项目使用蒙特卡洛方法，模拟矿井巷道网络中某一点持续出水后，水如何沿着网络逐渐扩张并累积。

模型将矿井看成一个无向图：

- 节点表示巷道交汇点或端点；
- 边表示矿井巷道；
- 每条边有长度和当前累计水位高度；
- 水从固定源点以恒定流量进入网络。

核心思想是将连续进入的水分成大量很小的“水滴”。每一滴水在网络中移动时，会根据候选巷道当前的水位高度进行随机选择。水位越低，被选择的概率越高；水位越高，被选择的概率越低。这样，水流会倾向于向低水位区域扩张，形成一种带负反馈的扩散过程。

## 问题背景

在矿井突水或巷道积水问题中，水可能从某个位置进入巷道系统，然后沿着互相连通的地下网络扩散。完整的物理模拟通常需要考虑流体动力学方程、巷道几何结构、坡度、水压、阻力、边界条件等因素。

本项目采用一种更简化的网络模型。它不追求精确描述每一处的流速和压力，而是关注每条巷道中水位高度的累计分布。这个模型适合用来探索：

- 哪些巷道更容易积水？
- 水位分布如何随时间变化？
- 局部水位反馈如何影响整体扩张？
- 当水倾向于避开已积水区域时，网络中的分布会如何演化？

## 模型假设

当前实现包含以下简化假设：

- 出水点流量恒定，为 `A`，单位为立方米每秒。
- 所有巷道宽度相同，为 `TUNNEL_WIDTH`。
- 矿井系统被表示为一个图结构。
- 每滴水到达节点后，不会立刻走回刚来的方向。
- 每滴水在单次路径中不会重复走同一条巷道，以避免在有环网络中无限循环。
- 当水滴到达死胡同，或没有可选的下一条巷道时，它停止移动。
- 水滴停止后，将其体积折算为高度增量，并累加到它经过的每一条巷道上。

## 算法流程

每一个模拟步中：

1. 计算单滴水的体积：

   $$
   V_{drop} = \frac{A \Delta t}{N_{drops}}
   $$

2. 从源点释放 `N_DROPS` 滴水。

3. 对每滴水，重复以下过程直到停止：

   - 找到当前节点所有可选的相邻巷道；
   - 排除刚来的方向，避免立即回头；
   - 排除这滴水已经走过的巷道，避免在环中无限循环；
   - 计算每条候选巷道的选择权重：

     $$
     w_i = e^{-\alpha h_i}
     $$

     其中 `h_i` 是候选巷道 `i` 当前的水位高度。

   - 将权重归一化为概率；
   - 按概率随机选择下一条巷道；
   - 将该巷道长度加入本滴水的累计路径长度。

4. 当水滴停止后，计算它对路径的水位贡献：

   $   \Delta h = \frac{V_{\text{drop}}}{L_{\text{path}} W}   $

   然后将 $\Delta h$ 加到这滴水走过的每一条巷道上。

5. 每隔 `SNAPSHOT_INTERVAL` 步保存一次中间结果。

## 基于水位的随机选择

本模型最重要的反馈机制是：

$$
P_i =
\frac{e^{-\alpha h_i}}
{\sum_{j \in C} e^{-\alpha h_j}}
$$

其中：

- `P_i` 是选择巷道 `i` 的概率；
- `h_i` 是巷道 `i` 当前的水位高度；
- `alpha` 控制水流避开高水位巷道的强度。
- `C` 是当前节点所有可选的下一条巷道集合。

当 `alpha` 较小时，水滴选择路径更接近均匀随机。

当 `alpha` 较大时，水滴会更明显地偏向低水位巷道。这样高水位区域会变得“不吸引”后续水滴，而低水位区域更容易继续接收水，从而形成一种平衡效应。

## 主要参数

主要参数位于 `simulation.py` 文件开头：

```python
ALPHA = 10.0
SOURCE = 0
RANDOM_SEED = None
A = 1.0
DT = 1.0
N_DROPS = 1000
STEPS = 100
SNAPSHOT_INTERVAL = 10
TUNNEL_WIDTH = 2.0
SHOW_PLOT = False
```

常见调整方式：

- 增大 `STEPS`：模拟更长时间。
- 增大 `N_DROPS`：结果更平滑，随机波动更小。
- 减小 `N_DROPS`：随机性更明显。
- 增大 `ALPHA`：水更强烈地避开高水位巷道。
- 设置 `RANDOM_SEED = 42` 或其他整数：让每次运行结果可复现。
- 设置 `SHOW_PLOT = True`：本地运行时弹出 matplotlib 图形窗口。

## 问题推广

虽然本项目以矿井水流为例，但这个算法可以推广为一类更一般的“网络累积量传播模型”。

它的基本模式是：

$$
P_i =
\frac{f(x_i)}
{\sum_{j \in C} f(x_j)}
$$

$$
x_i(t + 1) =
x_i(t) + \Delta x_i
$$

其中，`x_i` 可以表示水位、拥堵度、负载、温度、浓度、风险等累计量；`f(x_i)` 表示路径选择对当前累计状态的响应函数。本项目中使用的是：

$$
f(x_i) = e^{-\alpha x_i}
$$

可以推广到的例子包括：

- 人群疏散：人沿走廊和出口移动，拥挤路径的吸引力下降。
- 交通分配：车辆在道路网络中选择路径，拥堵道路被选择概率降低。
- 信息传播：消息在社交网络中扩散，过载或饱和的通道减少后续传播。
- 热量累积：热量包在结构网络中传播，温度较高的边吸引力下降。
- 污染物或泥沙输运：粒子沿河道网络移动，局部浓度影响后续路径选择。
- 网络负载均衡：计算任务在服务器网络中传播，避开已经高负载的链路。
- 疾病暴露累积：暴露粒子在接触网络中传播，路径上的风险或暴露量逐渐累积。
- 资源或资本分配：小单位资源在供应链或金融网络中流动，避开已经饱和的路径。

在这些问题中，“水位高度”可以被替换成其他累计量，例如拥堵度、负载、温度、浓度、风险、需求或饱和程度。

## 模型局限

当前模型是一个探索性简化模型，还没有包含：

- 巷道坡度或重力方向；
- 水压；
- 流速；
- 中间节点处严格的水量守恒；
- 巷道容量上限；
- 排水或外流；
- 随时间变化的出水流量；
- 不同巷道宽度；
- 物理阻力或摩擦。

如果需要更接近真实水动力学的模型，可以在这些方向上继续扩展。
